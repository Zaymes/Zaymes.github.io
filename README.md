# James Shrestha - Professional Website

A modern, professional website showcasing my work, projects, and writings in the fields of technology, data, and civic innovation.

## About

This is my professional portfolio website built with Next.js and deployed as a static site. It features a clean, modern design with smooth animations and a responsive layout that works seamlessly across all devices.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Static export for GitHub Pages

## Features

- ✨ Modern, clean design
- 📱 Fully responsive
- 🌓 Dark mode support
- ⚡ Optimized for performance
- 🎨 Smooth animations and transitions
- 📝 Easy content management

## Build & Deploy

The site is configured for static export and can be deployed to any static hosting service:

```bash
cd site
npm install
npm run build
```

The static files will be generated in the `out/` directory, ready for deployment.
